# বিদ্যুৎ বিল ম্যানেজমেন্ট সিস্টেম

একটি সম্পূর্ণ ওয়েব-ভিত্তিক বিদ্যুৎ বিল ম্যানেজমেন্ট অ্যাপ্লিকেশন।

## বৈশিষ্ট্যসমূহ

- 🔐 ইউজার লগইন ও রেজিস্ট্রেশন
- 🔌 একাধিক মিটার ম্যানেজমেন্ট
- 💰 ট্রানজেকশন ট্র্যাকিং (রিচার্জ ও বিল)
- 🧮 ৮টি ভিন্ন ক্যালকুলেটর
- 📊 রিপোর্ট ও এনালিটিক্স
- 🌙 ডার্ক মোড সাপোর্ট
- 📱 PWA সাপোর্ট (অফলাইন)
- 💾 অটো ব্যাকআপ সিস্টেম

## কিভাবে ব্যবহার করবেন

1. সব ফাইল একটি সার্ভারে আপলোড করুন
2. index.html ফাইল ওপেন করুন
3. প্রথমে রেজিস্টার করুন
4. একটি মিটার যোগ করুন
5. ট্রানজেকশন যোগ করা শুরু করুন

## অ্যাডমিন অ্যাক্সেস
