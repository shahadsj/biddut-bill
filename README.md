---

## 🌟 **ফিচারসমূহ**

### 📊 **ড্যাশবোর্ড**
- ৬টি কালারফুল স্ট্যাটাস কার্ড (রিচার্জ, খরচ, ট্রানজেকশন, KWH)
- ব্যালেন্স প্রগ্রেস বার (১০টি লেভেল)
- ডিমান্ড চার্জ, ভ্যাট ও রিবেট সারাংশ
- সর্বশেষ ট্রানজেকশন টেবিল

### ⚡ **মিটার ম্যানেজমেন্ট**
- একাধিক মিটার যোগ/এডিট/ডিলিট
- প্রতিটি মিটারের আলাদা ট্রানজেকশন
- বাংলা ও ইংরেজি নাম সাপোর্ট

### 💳 **ট্রানজেকশন**
- রিচার্জ ও বিল এন্ট্রি
- স্ল্যাব ভিত্তিক ইউনিট ক্যালকুলেশন
- অটো ব্যালেন্স আপডেট
- মাসিক রিচার্জ (ডিমান্ড চার্জ + ভ্যাট + রিবেট)

### 🏠 **ভাড়া ব্যবস্থাপনা**
- মাসিক ভাড়া ট্র্যাকিং
- সার্ভিস চার্জ ও পার্কিং চার্জ
- স্ট্যাটাস (পরিশোধিত/বাকি/অতিদিন)
- কমা সেপারেটর সহ সংখ্যা ফরম্যাট

### 🛒 **অতিরিক্ত খরচ**
- বাজার, গ্যাস, ইন্টারনেট, মোবাইল, বিদ্যুৎ, পানি, মুদি, অন্যান্য
- ইউজার ভিত্তিক ডাটা (মিটার মুক্ত)
- ৮টি ক্যাটাগরিতে খরচ বিশ্লেষণ

### 📈 **রিপোর্ট ও এনালিটিক্স**
- মাসিক ভাড়া রিপোর্ট
- স্ল্যাব বিশ্লেষণ
- চার্ট সহ এনালিটিক্স
- Excel এক্সপোর্ট

### 🔧 **সেটিংস**
- VAT রেট, রিবেট রেট, ডিমান্ড চার্জ
- ট্যারিফ রেট আপডেট
- ডার্ক মোড
- হাই কনট্রাস্ট মোড
- ফন্ট সাইজ কন্ট্রোল

### 💾 **ব্যাকআপ**
- JSON ব্যাকআপ
- ZIP ব্যাকআপ
- ডাটা রিস্টোর

### 👑 **অ্যাডমিন প্যানেল**
- ইউজার ম্যানেজমেন্ট
- অ্যাক্টিভিটি লগ

### 🌙 **থিম**
- লাইট মোড
- ডার্ক মোড
- হাই কনট্রাস্ট মোড

### 🌐 **ভাষা**
- বাংলা (bn)
- ইংরেজি (en)
